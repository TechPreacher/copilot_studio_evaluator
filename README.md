# Microsoft Copilot Studio RAG Agent Evaluator

This repository builds upon the Microsoft 365 Agents C#/.Net SDK by adding an evaluation client that allows testing for Copilot Studio based RAG agents.

Groundedness and document retrieval can be evaluated/tested and automated with this tool.

Please refer to the M365 Agents SDK overview and C#/.Net SDK documentation for more details on writing custom code that can access Microsoft Copilot Studio based agents.

- Microsoft 365 Agents SDK Overview: https://github.com/microsoft/Agents
- Microsoft 365 Agents C#/.Net SDK: https://github.com/Microsoft/Agents-for-net

In the end, I hope this repository will make it into the M365 Agents SDK samples so that this repository here can be dropped.

See the [README](./src/samples/EvalClient/README.md) file of the evaluator for details on how to configure and use this evaluator.
